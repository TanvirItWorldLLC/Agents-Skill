## Search Qualifiers

- `is:featured` — topics with most repos
- `is:curated` — community curated topics with extra info
- `repositories:>5000` — topics with 5000+ repos
- `topic:nextjs` — search repos by topic

## Usage

```bash
# Browse topic page
open https://github.com/topics/<topic-name>

# Search repos by topic
open https://github.com/search?q=topic:nextjs+topic:turborepo&type=Repositories
```
